# শিপিং দেরি সতর্কতা অ্যাপ: খরচ ও লাভের হিসাব (যাচাইয়ের পরে হালনাগাদ)

> সব সংখ্যা আনুমানিক, সার্চ রেজাল্ট থেকে নেওয়া। পূর্ণ সূত্রের তালিকা নিচে। কোড লেখার সময় প্রতিটা সার্ভিসের নিজের ডক আর প্রাইসিং পেজে আবার মিলিয়ে নিতে হবে।

## যাচাই ১: Shopify কোন পার্সেলের খবর ফ্রিতে দেয়?

- Shopify-র API ডকে (`FulfillmentTrackingInfo`) "স্বয়ংক্রিয় আপডেট পাওয়া কুরিয়ার"-এর আলাদা একটা তালিকা আছে। শুধু ট্র্যাকিং নম্বর চেনা মানে কেবল লিংক তৈরি, স্ট্যাটাস আপডেট নয়।
- Shopify-র এক কর্মীর ফোরামে দেওয়া উত্তর: "পথে আছে" বা "পৌঁছেছে" স্ট্যাটাস **পুরোপুরি আসে শুধু Shopify থেকে লেবেল কিনলে।** অনেক দোকানদার অভিযোগ করেছেন যে সমর্থিত কুরিয়ারেও স্ট্যাটাস আটকে থাকে।
- **সিদ্ধান্ত:** ফ্রি তথ্যের ওপর পুরো ভরসা করা যাবে না। হিসাব করতে হবে এমনভাবে যেন **সব পার্সেলের জন্য পেইড ট্র্যাকিং লাগলেও লোকসান না হয়।** ফ্রি তথ্য পাওয়া গেলে সেটা বাড়তি লাভ।

## যাচাই ২: সবচেয়ে সস্তা ট্র্যাকিং সার্ভিস কোনটা?

| সার্ভিস | দাম | প্রতি পার্সেল |
|---|---|---|
| **Ship24** | $৩৯ / ১,০০০ · **$৯৯ / ৫,০০০** · $৩৪৯ / ২৫,০০০ · $৫৯৯ / ৫০,০০০ · ফ্রি টিয়ার আছে | $০.০৩৯ → **$০.০২** → $০.০১৪ → $০.০১২ |
| 17TRACK | $১১৯ / ৫,০০০ (বছরে আগাম) | $০.০২৪ |
| TrackingMore | $৭৪ / ২,০০০ (মাসিক) | $০.০৩৭ |
| ParcelsApp | $৯ / ১০০ | $০.০৯ |
| কুরিয়ারের নিজের API (USPS, UPS, FedEx, DHL) | ফ্রি বলে দাবি, কিন্তু সীমা কম (যেমন DHL দিনে ২৫০টা) | $০, তবে বড় পরিসরে নির্ভরযোগ্য না |

**সিদ্ধান্ত:** তিন ধাপে তথ্য নেওয়া হবে: (১) Shopify-র ফ্রি স্ট্যাটাস → (২) কুরিয়ারের ফ্রি API, যতক্ষণ সীমার মধ্যে থাকে → (৩) Ship24। শুরুতে Ship24-এর ফ্রি টিয়ার, পরে $৩৯ বা $৯৯ প্ল্যান। এই হিসাবে পেইড ট্র্যাকিং ধরা হয়েছে প্রতি পার্সেল **$০.০২**।

> ⚠️ মনে রাখার মতো: Ship24-এর প্ল্যানগুলো মাসিক নির্দিষ্ট ফি। গ্রাহক কম থাকলে $৩৯ প্ল্যানের ফি স্থায়ী খরচের মতো আচরণ করবে।

## যাচাই ৩: বাংলাদেশে টাকা আনার খরচ

- Shopify সবসময় **USD-তে** পেমেন্ট দেয়। অন্য মুদ্রায় নিলে Hyperwallet ০.৫% রূপান্তর ফি কাটে।
- Payoneer চলবে না, আসল ব্যাংক অ্যাকাউন্ট লাগবে।
- Shopify-র নিজের বাংলাদেশ ফি প্রকাশিত নেই। Hyperwallet-এর অন্য একটা প্রোগ্রামে বাংলাদেশি ব্যাংকে BDT পাঠানোর ফি দেখানো আছে প্রায় **৫০৫ টাকা বা ২–৩%।** আরেকটা প্রোগ্রামে ফি শূন্য।
- **সিদ্ধান্ত:** হিসাবে আয়ের **৩%** টাকা আনার খরচ ধরা হলো। আসল ফি দেখা যাবে Partner Dashboard-এর payout পেজে।

- Shopify: FulfillmentTrackingInfo API ডক, Shipping carriers ও Order tracking হেল্প পেজ, Shopify Developer Community থ্রেড
- Ship24 ব্লগ (শিপমেন্ট ট্র্যাকিং API তুলনা; Ship24 নিজের পক্ষে পক্ষপাতদুষ্ট হতে পারে), TrackingMore Tracking API পেজ

### দাম নিয়ে সিদ্ধান্ত

- **৫০ অর্ডারের ফ্রি প্ল্যান** বাজারের নিয়ম (DelayRadar, LateKit, Track123, AfterShip)। আমাদেরও তাই।

- **সাধারণ ট্র্যাকিং অ্যাপের তুলনায়:** আমরা দামি (ওরা $৯–১১ থেকে শুরু)। তাই এদের সাথে দামে লড়াই করা যাবে না। লড়তে হবে বাড়তি সুবিধা দিয়ে: কাস্টমারের নিজের ভাষায় AI মেসেজ, দেরি আগেভাগে ধরা, আর কাস্টমারের উত্তরের খসড়া বানিয়ে দেওয়া।
- **সুযোগ:** TrackingMore-এর Shopify অ্যাপ বন্ধ হলে তার ব্যবহারকারীরা নতুন অ্যাপ খুঁজবে। তবে এই খবরটা যাচাই করা দরকার।
